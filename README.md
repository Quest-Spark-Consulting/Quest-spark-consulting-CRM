# CoachSync Micro-Coaching CRM

A premium, collaborative CRM system designed for micro-coaching progress tracking and conversion analysis.

## Features
- **Collaboration Ready**: Designed for real-time syncing across coaching teams.
- **Progress Tracking**: Log weekly coaching notes and view progress timelines.
- **Weekly Reporting**: Dedicated view for "Thursday progress discussions" and conversion funnel analysis.
- **WhatsApp Integration**: Quick-dial links with pre-filled professional messages.
- **Premium Design**: Dark mode with glassmorphism aesthetics and responsive layout.

## Setup & Hosting
This is a static web application (HTML/CSS/JS).

### Quick Start
1. Clone this repository or download the ZIP.
2. Open `index.html` in any modern web browser.

### Hosting on GitHub Pages
1. Create a new repository on GitHub.
2. Upload all files from this folder.
3. Go to **Settings > Pages**.
4. Select `main` branch as the source and click **Save**.
5. Your CRM will be live at `https://yourusername.github.io/your-repo-name/`.

## Data Syncing
By default, data is saved locally in your browser. To enable sharing between users:
1. Create a free project on [Supabase](https://supabase.com/).
2. Add your project URL and API Key in `app.js`.
3. Click "Sync Cloud" to share data with your team.
