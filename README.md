# Quest Spark Client CRM

A premium, cloud-connected CRM system designed for micro-coaching businesses. 

## Features
- **Supabase Integration**: Real-time cloud data synchronization.
- **WhatsApp Quick-Dial**: Instant communication with clients.
- **Professional Reporting**: CSV and PDF export for weekly progress meetings.
- **Dual Portal**: Separate dashboards for Coaches and Clients.
- **Glassmorphic Design**: Modern, high-end UI/UX.

## Setup
1. Clone the repository.
2. Open `index.html` in any browser.
3. Configure your Supabase credentials in the `<script>` section if you wish to use your own database.

## Built With
- HTML5 / CSS3 (Vanilla)
- Javascript (Vanilla)
- Supabase (Backend as a Service)
- Lucide Icons
